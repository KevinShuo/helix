# 文件浏览器的「移动到…」

## 接续位置

文件浏览器的 `F4` 菜单已有新建文件、新建目录、重命名和删除。「移动到…」沿用此菜单。

## 建议交互

1. 在普通文件浏览器中选中一个文件或目录，按 `F4` → `v` 打开「移动到…」。现有的 `m` 继续用于新建目录。`../` 仅用于导航。
2. 目录选择器从当前浏览目录打开，标题显示待移动项的名称。输入文字筛选目录，`Enter` 进入选中目录，`../` 返回上一级。
3. 底部显示将要写入的完整目标路径。目标由**当前浏览到的目录**和源项原名组成。例如，选中 `fetch.py` 后进入 `models/`，目标路径末尾应为 `models/fetch.py`。
4. 按 `F4` 确认移动到当前目录。按 `Esc` 取消，恢复源浏览器的目录、筛选词和选中行。

## 首版范围

- 单次移动一个文件或整个目录，保留原名。移动前检查目的地，同名冲突时显示冲突路径，保留选择器供用户改选。实际移动也须防止覆盖。
- 原目录、源目录自身及其子目录均不可作为目的地。禁用确认并说明原因。检查目录关系时应考虑符号链接和 Windows 目录联接。
- 移动已打开的文件时同步更新缓冲区路径，保留未保存的编辑。移动目录时同样处理已打开的子文件。
- 首版仅支持同一文件系统内的移动。跨盘时提示暂不支持，保留源项和当前选择器。

## 移动成功后的焦点

移动成功后跟随到目标目录，选中移动项并刷新预览，方便按 `Enter` 接着编辑。

## 实现入口和验收

菜单入口在 `helix-term/src/ui/picker/file_actions.rs`，目录导航在 `helix-term/src/ui/mod.rs`。可复用编辑器的 `Editor::move_path_noreplace` 来执行移动并更新缓冲区路径。选择目的地期间需要保留源浏览器状态，以便取消后原样返回。

在 `helix-term/tests/test/commands/file_explorer.rs` 中通过真实按键覆盖移动文件、移动含未保存缓冲区的目录、取消后恢复筛选、重名保护、拒绝移入自身或子目录，以及成功后的焦点和预览。
