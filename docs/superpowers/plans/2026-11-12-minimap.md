# Configurable Minimap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an opt-in terminal code minimap with syntax-colored Braille, block fallback, navigation and existing diagnostic/Git markers.

**Architecture:** Share a bounded source summary per document, project it into each split's right-hand area, and calculate text geometry through one layout helper. Debounce and build summaries in short main-loop jobs; input uses separate drag capture and absolute source navigation.

**Tech Stack:** Existing Rust workspace, Rope, Tree-sitter, serde/TOML, helix-event jobs and helix-tui; no new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-12-minimap-design.md`

## Global Constraints

- Default `enabled=false`; fields `width=16`, `render="braille"`, `min-editor-width=60`, `diagnostics=true`, `git-diff=true`.
- Width 8–40 inclusive; minimum text width at least 20. Width includes separator and two permanent marker columns.
- Braille 2×4, blocks 2×2; fit source lines without stretching short files; first 160 display columns.
- Source summaries exclude virtual annotations; fold/soft-wrap state changes only viewport overlays.
- At most 128 source lines / 32KiB per construction slice, target 3ms; debounce 150ms.
- Over 50,000 lines or 4MiB use bounded monochrome sampling; cap each source line at 4,096 characters.
- Preserve existing unrelated local changes; reuse current feature checkout, no merge/push/deployment or user-config edits.

## Review Focus

- Canceled drags and release after config/resize/buffer changes must never copy or edit text.
- Syntax/language reload at unchanged text version must invalidate source colors.
- Empty/huge/long-Unicode lines must keep indexing and work bounded.
- A fold containing the navigation destination must reveal without losing secondary selections.
- Runtime enabling and split resize must keep all text layout and screen-coordinate helpers consistent.
