# Native Git Tools Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task by task.

**Goal:** Ship the approved bottom/fullscreen Git workspace under Space v.

**Architecture:** An async helix-vcs Git CLI API supplies immutable snapshots,
details and patches. A helix-term component owns pane selection, query
cancellation and docking; its commands live in a dedicated Git module.

**Tech Stack:** Rust 1.90, Tokio, existing Helix compositor/TUI, Git CLI.

**Spec:** docs/superpowers/specs/2026-11-11-git-tools-design.md

## Global Constraints

- Preserve Space g; group all new commands under Space v.
- Default bottom; F11 toggles fullscreen without resetting state.
- No new dependencies, respect trust, keep feature-disabled builds compiling.
- Mutations require explicit UI actions; never force or silently discard data.
- Work in the existing checkout on codex/git-tools; no remote publication.

## Review Focus

- Paths with whitespace, Unicode, renames or deletion must select the right diff.
- Empty/detached/worktree repositories must not fail initial rendering.
- Fast selection/filter changes and closing/reopening cannot apply stale results.
- Docking must resize editor views and restore them on close and resize.
- Unsaved buffers must survive branch changes; mutation errors must be visible.
