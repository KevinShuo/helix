# File explorer actions

Implement the approved F4 menu in the existing directory picker.

- Exercise create, rename, delete, cancel, and filtering through the terminal integration harness.
- Attach the menu only to directory explorers. Keep the picker alive while editing a name or confirming deletion.
- Validate the chosen name and target, preserve open buffers on rename, and restrict deletion to clean files and empty directories.
- Refresh directory entries and previews after successful operations, retaining the filter when it can show the target.
- Document the shortcuts and verify the integration tests, formatting, and build.
