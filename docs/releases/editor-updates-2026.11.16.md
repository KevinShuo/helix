# Helix Windows x64 · AI 提交修复 · 2026.11.16

## 更新

- 修复中文文件摘要容易触发 `AI/commit text is empty or too long`：摘要按最多 160 个 Unicode 字符校验，并保留总请求字节和模型上下文预算。
- 提交文本校验现在区分摘要、推荐理由、标题、正文和手动提交信息，分别报告空文本、实际长度、上限和不支持的控制字符。
- 修复 AI 误选已有暂存、部分暂存或未完整分析的文件时整次推荐中断的问题：保留合规候选，排除不合规建议并显示中文说明。未知或重复文件 ID 仍会被拒绝。
- 推荐只调整候选勾选，不写入暂存区；部分暂存内容不会被自动覆盖。已有暂存文件始终包含在实际提交中。
- 同时包含上一版本之后 master 上的 AI 冲突合并预览、命名模型集成和上游同步更新。

## 使用

完整解压 Windows x64 ZIP，保持 `hx.exe` 与 `runtime` 同目录。包内包含使用说明、示例配置、许可证、逐文件校验清单和 `BUILDINFO.json`；个人配置、密钥、模型及模型服务程序不包含在发布包中。

`:ai-commit` 中，`a` 推荐候选、空格调整、`s` 暂存、`g` 根据真实暂存区生成提交信息、`e` 编辑、大写 `C` 提交。已有文件暂存时可以直接 `g`。

提交范围改变或 AI 分析不完整时，草稿需要重新生成或明确检查；核对完整 diff 和草稿后，按 `v` 保留当前文本，再按大写 `C` 提交。不会自动跳过这项检查。

已运行的旧编辑器会话需要保存并重启以使用新程序。Windows 10/11 x64 需 Microsoft Visual C++ v14 x64 运行库；Git、语言服务器、AI provider 和测试框架按需配置。
