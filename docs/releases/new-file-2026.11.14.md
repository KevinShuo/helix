# Helix Windows x64 · 同目录快速新建文件 · 2026.11.14

## 新功能

- 普通模式依次按 `Space`、`n`，输入文件名并回车，即可在当前文件所在目录打开新缓冲区，自动进入插入模式。
- `:w` 时才创建磁盘文件；`Esc` 取消，不产生文件。
- 支持中文、空格和子目录路径。父目录不存在时，使用 `:w!` 创建目录并保存。
- 已有文件及同名未保存缓冲区会被拦截，包括 Windows Unicode 大小写重名。
- 同时提供 `:new-file <文件名>`；原有 `:new` 保持创建无名缓冲区。
- 修正从输入提示进入插入模式时的记录，`.` 可正常重复本次输入。

## 使用

下载 Windows x64 ZIP 并完整解压，运行其中的 `hx.exe`。包内附带完整 runtime、中文说明、示例配置、许可证和 `BUILDINFO.json`。`SHA256SUMS.txt` 提供下载校验。

本机正在运行的旧 Helix 会话需要保存工作并重启，才能加载新版程序。个人配置不随发布包分发，也不会被本机更新覆盖。
