# Helix Windows x64 · Python 字符串引号补全修复 · 2026.11.14

## 修复

- Python 文件中输入 `r"` 会自动补齐右引号，光标停在两个引号之间。
- 再次输入 `"` 时跳过已有右引号，避免原来的额外引号。
- 支持单双引号、字符串前缀的大小写，以及 `r`、`b`、`u`、`f`、`t` 和合法的双字母组合。
- 前缀须位于完整标识符边界；支持 Unicode 标识符，避免将变量名末尾的字母误判为字符串前缀。
- 支持多光标和嵌入语言；遵循关闭自动配对的配置。
