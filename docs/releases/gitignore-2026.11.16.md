# Helix Windows x64 · .gitignore 模板生成 · 2026.11.16

## 新功能

- 新增 `:gitignore` 和 `Space v i`：检查项目根目录的标志文件，自动推荐语言与构建工具模板。
- 内置 19 个模板，覆盖 Rust、Node、Python、Go、Java、C/C++、.NET、Maven、Gradle、CMake，以及操作系统、编辑器、临时文件和 dotenv 通用规则；离线可用。
- 支持搜索和模板组合：方向键移动，Tab 勾选，Enter 生成，Esc 取消。搜索隐藏的已选模板仍会保留。
- 生成后打开未保存的 `.gitignore` 草稿，检查修改后用 `:w` 保存。已有文件或同路径缓冲区直接打开，保留原内容；兼容 Windows 大小写不同的未保存文件名。
- 保留模板内部的规则和例外顺序、锁文件及 dotenv 示例；草稿统一使用 LF。选择期间或打开草稿时出现的外部文件不会被模板替换。

## 使用与范围

完整解压 Windows x64 ZIP，保持 `hx.exe` 与 `runtime` 同目录。包内包含中文使用说明、示例配置、许可证、逐文件校验清单和 `BUILDINFO.json`，附件提供 SHA-256 校验值。

只识别根目录，不扫描子项目；操作系统、编辑器和通用模板需要手动勾选。已有 `.gitignore` 不会自动合并或追加。Git 已跟踪的文件不会因新规则自动停止跟踪。

本次公开发布只包含已提交源码；工作区尚未提交的 AI 改动不进入发布包。个人配置、密钥、模型和模型服务程序不分发。本机更新独立构建并保留已有 AI 改动及个人配置，旧编辑器会话保存后重启即可加载新程序。

Windows 10/11 x64 需 Microsoft Visual C++ v14 x64 运行库。Git、语言服务器、AI provider 和测试框架按需另行配置。
