# Helix Windows x64 · 共享 AI 与开发功能补全 · 2026.11.17

本次发布将已完成但尚未发布的 AI 进度、预算、预览改动与跨 hx 模型共享一起提交到本仓库的 master，并从该提交构建 Windows x64 程序。

- 多个 hx 共用当前用户的本地模型管理器。完整推理操作按队列执行，关闭首个编辑器不会停止其他实例的模型；临时 27B 任务完成后恢复 9B 补全，最后一个客户端退出后自动释放模型。
- AI 提交窗口显示当前阶段、批次、已分析文件、需手查数量，以及持续更新的总耗时和本步耗时。受管本地 llama.cpp 每秒读取实际生成 token 数；接口不可用或在线模型显示“暂不可用”。取消和配置切换会停止对应监测。
- 保留可配置的提交文件上限和较大的本地生成预算；按 provider 应用 auto/configured 预算、有限重试与完整输出校验。自动行内补全仍使用适合短补全的限额。
- 文档、测试、冲突解决和提交可处理较大的完整结果。文档、测试与冲突预览支持完整滚动及 Home/End，避免超过 65535 行后无法查看尾部。
- 文档生成使用可见源码、同文件辅助函数和常量，并验证描述的原文证据；必要时在同一操作中尝试一次修订。
- 包含此前已发布的 `.gitignore` 模板生成器、Git 工具、测试生成和运行、本地推理性能参数等功能。

## 为什么此前的 Release 缺少处理进度

此前最新发布 `local-ai-performance-2026.11.16` 对应提交 `d9d9cb33`。进度/token 计数、provider 预算和大预览当时只存在于本地未提交文件；本地安装曾包含这些内容，但从已提交源码制作的远端发布包没有包含它们。共享模型和源码证据文档生成也晚于该发布提交。

本次将这些源码和回归测试一并提交。发布附件 `BUILDINFO.json` 记录准确提交、功能覆盖和验证结果，`MANIFEST.sha256` 校验解压后的文件，`SHA256SUMS.txt` 校验发布附件。

完整解压 ZIP，保持 `hx.exe` 与 `runtime` 同目录。包内含示例配置和中文说明；保留现有个人配置并重启旧编辑器。发布包不含个人配置、凭据、模型权重或 llama.cpp，不会自动下载或改写模型设置。Windows 10/11 x64 需要 Microsoft Visual C++ v14 x64 运行库。

本次交付 Windows x64 包。macOS/BSD 保留原本地后端，未宣称已获得 Windows/Linux 的跨进程共享能力。在线模型的实时 token 监测未实现。
