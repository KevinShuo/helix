# Helix AI 结果阅读

标题标明当前操作，文件、函数、选区行号和冲突块取自编辑器快照。首屏显示眼下要阅读或确认的内容，键位提示随当前状态改变。[七种场景的交互原型](ai-results-preview.html)

| 场景 | 阅读与验收 |
| --- | --- |
| 选区问答 | 显示选区来源、用户问题与回答。段落、列表、代码和引用行号可辨，长回答可翻页。Enter 追问使用同一快照，Esc 收起后可重新打开。 |
| 光标生成 | 需求在光标附近输入，生成内容在真实插入点显示为灰字。再次补充需求时基于已有草稿，Shift-Right 接受一次，Esc 放弃。 |
| 行内补全 | 建议紧接正在输入的文本，输入匹配前缀后继续显示剩余文本。颜色跟随当前主题，Shift-Right 接受后内容成为普通正文。 |
| 函数文档 | 显示函数及实际待插入注释，保留语言注释符、缩进与换行。Enter 插入，r 重试，Esc 取消。 |
| 测试 | 待接受时显示目标函数、文件路径和逐文件差异。Enter 接受改动，Esc 取消，r 重试。运行后先显示阶段、成败、可识别的测试计数与失败诊断。l 打开或收起原始输出，v 再次运行。阅读修复日志时 Enter 返回候选修改。 |
| 冲突建议 | 显示文件和冲突块编号。用 −/+ 和主题颜色区分当前块与候选块，能看到完整替换、删除、末尾换行差异及模型解释。存在候选时提供 Enter 接受，接受后仍按已有流程审阅 Result。需人工处理时可用 r 重试或 Esc 取消。 |
| 提交说明 | 标题与正文分层，保留提交文本的换行与编辑能力。编辑时 Enter 换行，Esc 或 Ctrl-s 结束编辑，提交前确认消息和暂存内容。 |

测试计数只取执行器明确输出的数据，编译或环境错误显示其诊断。只有同一段输出明确标出 expected 和 actual 时才展示期望与实际。普通相等断言保留原文。日志缺少计数或断言时仍可查看完整采集输出。

新增、删除、失败和状态均有文字或前缀，颜色取自当前主题。差异中的 ⇥ 表示制表符，␍ 表示回车。长行按字形宽度换行，续行继承原行的样式。窄屏保留可滚动正文及当前可用的确认、取消或返回键。测试和冲突预览均在明确接受后才修改缓冲区。
