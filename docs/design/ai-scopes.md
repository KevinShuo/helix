# 在工作台里选择代码范围

`:ai` 的「解释代码」和「优化代码」共用解释模型。执行前可看到当前文件、选区或光标行、所选范围、工程根和模型。按 Enter 执行后才发送请求。

| 操作 | 可选范围 | 直接命令 |
| --- | --- | --- |
| 解释代码 | 选区、函数或声明、当前文件、工程 | `:ai-explain selection`、`:ai-explain function`、`:ai-explain file`、`:ai-explain project` |
| 优化代码 | 选区、函数或声明、当前文件 | `:ai-optimize selection`、`:ai-optimize function`、`:ai-optimize file` |

↑↓ 或 j/k 选择操作。解释、优化两行用 Tab 或 → 切到下一范围，Shift-Tab 或 ← 切回上一范围，Enter 执行。两行各自记住本次打开工作台时选过的范围。s 打开设置，其他操作行也可用 Tab 进入设置。从设置按 Tab 或 a 回到操作页。

已有选区时默认选择选区。只有光标时，范围优先取其所在的函数或声明。找不到符号时可以手动选择文件，解释代码也可选择工程。执行后，结果标题显示实际来源。Enter 在原范围中追问，工程问答可针对新问题查阅其他相关文件。Ctrl-C 停止当前请求，Esc 收起对话并保留输入草稿。

工程解释可查找文件、检索源码、读取指定行，以及查找符号定义或引用。选区、函数、文件问答中按 Alt+E「查工程」可为本次会话开启这些工具，优化建议返回后也可使用。输入框有内容时发送当前问题，留空时继续查证上一问。此后按 Enter 追问可继续查同一工程，原代码或优化对象保持为讨论主题。

本地模型和 DeepSeek 都沿用工作台中显示的解释模型。回答会保留最初选择的代码快照，每次查工程则读取发起该轮问题时打开的缓冲区和工程文件。如果期间编辑过代码，原选区和新查到的内容可能来自不同版本。

正在查阅时，面板显示当前步骤。按 Alt+T 展开本轮查阅记录，用 ↑↓ 或 PgUp/PgDn 翻阅，再按 Alt+T 或 Esc 返回回答。查阅期间在回答或记录页按 Ctrl-C 停止。编辑器优先使用已打开缓冲区所连接的语言服务器定位定义和引用，无法取得语义结果时显示文本候选。Alt+G 可打开本轮实际查阅的源码位置。

结果提供可跳转的源码位置时，Alt+G 打开位置列表。用 ↑↓ 选择文件和行号，Enter 回到编辑器查看，Esc 返回阅读。优化结果中，Alt+P 打开按序号排列的建议。「可预览」表示有候选改动，Enter 查看差异，或使用 `:ai-optimize-preview N`。在差异页再次按 Enter 应用这一条，按 Esc 返回阅读。只有分析文字的条目标记为「仅建议」。

在 `:ai` 中选择「返回最近问答」或「返回最近优化建议」可恢复收起的结果，也可以直接执行 `:ai-explain-show`。
