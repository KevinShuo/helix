# Built-in ignore templates

These concise templates were authored for Helix's gitignore generator. They
are original project source under the repository's MPL-2.0 license, not copies
of an upstream template snapshot. No external assets or downloaded templates
are required to build or use the generator.

Pattern semantics: https://git-scm.com/docs/gitignore
Related template collection (reference only): https://github.com/github/gitignore

Keep each template's rule order, especially negations. Do not ignore lockfiles,
source trees or build wrappers. Add behavior tests when modifying rules.
